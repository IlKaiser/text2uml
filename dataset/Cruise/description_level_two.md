A specific provider organizes each cruise. Every provider has a name and a location. A cruise is identified by a number and a name. It also has a start date and an end date. Each cruise requires many employees. Every employee has a name and a social security number.

Several guests take part in a cruise. Each guest has a name, and it is noted whether the guest is a VIP or not. A guest can also take several cruises.

For each ship, the name, the number of decks, the length, and the number of passengers are known. A ship can be used for different cruises.

A cruise is booked through a travel agency. Each booking has a unique booking number and a booking date. A travel agency has a name and an address.

A cruise always heads for a specific destination area. Each destination area has a name, and the name of its sea is also noted. On a cruise, guests are offered several shows. Each show has a title and a certain duration.

A cruise has several guests, and each guest can take part in several cruises. Several tickets are issued for each cruise. A ticket belongs to exactly one cruise. A guest can have any number of tickets, but only one ticket per cruise.
