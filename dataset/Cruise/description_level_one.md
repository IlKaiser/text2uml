A provider organizes a cruise. Each provider has a name and a location. A cruise has a number and a name. It also has a start date and an end date.

A cruise needs many employees. Each of these employees works on it. Each employee has a name and a social security number.

Several guests take part in a cruise. Each guest has a name. We also note whether the guest is a VIP. A guest can take several cruises.

Each ship has a name. We know the number of its decks. We also know its length. We know how many passengers it holds. A ship can be used for different cruises.

A cruise is booked through a travel agency. Each booking is made for a cruise. It has a unique booking number. It also has a booking date. A travel agency has a name and an address.

A cruise always heads for one destination area. Each destination area has a name. We also note the name of its sea.

On a cruise, guests are offered several shows. Each show has a title. It also has a certain duration.

A cruise has several guests. Each guest can take part in several cruises.

Several tickets are issued for each cruise. A ticket belongs to exactly one cruise. A guest can have any number of tickets. But the guest can have only one ticket per cruise.
