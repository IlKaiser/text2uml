The Louvre Museum in Paris is a huge museum. It has many rooms. So the Museum can run many exhibitions at the same time. The planning of an exhibition starts at least two years before its opening date. So even one room may hold several exhibitions at once. These exhibitions are in different stages. They must all be followed up at the same time. So a small management system is needed. It makes sure all these exhibitions run smoothly.

The museum has picked a set of locations inside the museum. These locations can hold exhibitions. Each location is like a museum inside the museum. A location can span a part of a floor or wing. It can also span a whole floor or wing. So each location gets a series of exhibitions.

Each exhibition is given an employee as coordinator. The employee works for the museum. First, the museum defines a series of desired exhibition items. Take an exhibition on Vincent Van Gogh as an example. The museum wants one item from his early period. It wants one pencil drawing with its matching painting. It wants one sunflower painting. It wants other items too.

For each desired item, the museum sources a suitable piece. The piece comes from collectors. Collectors own candidate pieces. For some items, only one unique piece is available. For other items, several pieces are available. These pieces come from different collectors. For example, there are several "Sunflower" paintings by Vincent Van Gogh. For each exhibition item, the system tracks what pieces are requested. It also tracks which collector each piece is requested from.

Junior employees are given a senior employee as coach. This helps share knowledge. The system also tracks this "coaching" relationship between employees.
