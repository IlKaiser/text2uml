The LabTracker software has two jobs. First, LabTracker helps doctors manage the requisition of tests and examinations for patients. Second, LabTracker helps patients book appointments for tests and examinations at a lab. In this description, "tests" and "examinations" mean the same thing.

A doctor writes a requisition. For the requisition, the doctor must give some details. The doctor gives a numeric practitioner number and a signature. The practitioner number and the signature are used for verification. The doctor also gives a full name, an address, and a phone number. The signature is a digital signature. A digital signature is an image of the doctor's real signature. The doctor also gives the date from which the requisition is valid.

The requisition must also show the patient's information. The patient's information includes an alpha-numeric health number. The patient's information includes a first name and a last name. The patient's information also includes a date of birth, an address, and a phone number. A doctor cannot prescribe a test for the same doctor. But a doctor can prescribe tests to someone else who is a doctor.

Several tests can go on one requisition. But combining tests works only if the tests belong to the same group. For example, only blood tests can be combined on one requisition. Or only ultrasound examinations can be combined. A blood test and an ultrasound examination cannot go on the same requisition.

Each test has a duration. The lab network defines each test's duration. Defining the duration makes it possible to schedule appointments. The duration of a test is the same at every lab. For some kinds of tests, the number of tests does not matter. Such tests take as long as a single test. For example, several blood tests can be done on one blood sample. Drawing the blood sample for one blood test takes the same time as drawing the blood sample for several blood tests.

A doctor may say that the tests on a requisition must be repeated. The doctor gives a number of times and an interval. The interval is weekly, monthly, every half year, or yearly. All tests on a requisition follow the same repetition pattern.

The doctor and the patient can view the results of each test. A result is either negative or positive. The doctor and the patient can also view the report that comes with the result.

Some tests need an appointment. Other tests are walk-in only. For example, x-ray examinations need an appointment. But blood tests are walk-in only. So a patient cannot make an appointment for a blood test. Some tests only need a sample to be dropped off. For example, a urine or stool sample only needs to be dropped off.

To make an appointment for a requisition, a patient selects a lab. The patient chooses the lab based on the lab's address and business hours. For requisitions with repeated tests, a patient can only make one appointment at a time.

The appointment confirmation shows several things. The confirmation shows a confirmation number. The confirmation shows the date and the start and end times. The confirmation shows the name of the lab and the lab's registration number. A patient can change or cancel an appointment at any time. But changing or cancelling within 24 hours of the appointment costs a change or cancellation fee.

Each lab sets its own fee. Each lab also sets its own business hours. All labs are open every day of the year. All labs offer all tests. A lab's business hours are the same from one week to the next. Each day, a lab is open from the lab's start time to the lab's end time. There are no breaks.
