The LabTracker software helps doctors. Doctors requisition tests. The tests are for patients. The LabTracker software helps patients. Patients book appointments. The appointments are for tests. The tests happen at a lab. Tests and examinations mean the same thing here.

A doctor creates a requisition. The doctor must provide a numeric practitioner number. The doctor must provide a signature. The number verifies the doctor. The signature verifies the doctor. The doctor must provide a full name. The doctor must provide an address. The doctor must provide a phone number. The signature is a digital signature. A digital signature is an image. The doctor has an actual signature. The image shows the signature. The doctor indicates a date. The requisition is valid from this date. The requisition must also show the patient information. This information includes an alpha-numeric health number. This information includes a first name. This information includes a last name. This information includes a date of birth. This information includes an address. This information includes a phone number. A doctor cannot prescribe a test for themselves. A doctor can prescribe tests to someone else. That someone else can be a doctor.

Several tests can be combined on one requisition. The tests must belong to the same group. For example, only blood tests can be combined. Alternatively, only ultrasound examinations can be combined. A blood test cannot join an ultrasound examination on one requisition. Each test has a duration. The lab network defines this duration. The lab then schedules appointments accordingly. The duration is the same at each lab. For some tests, the number does not matter. These tests take as long as a single test. For example, several blood tests use one blood sample. A lab draws one blood sample for several blood tests. This takes as long as one blood test.

A doctor may repeat the tests. The requisition holds these tests. The doctor specifies a number of times. The doctor specifies an interval. The interval is weekly, monthly, every half year, or yearly. All tests on a requisition follow the same repetition pattern.

Each test has a result. The result is either negative or positive. Each test has an accompanying report. The doctor can view the result. The doctor can view the report. The patient can view the result. The patient can view the report.

A patient must make an appointment for some tests. Other tests are walk-in only. For example, x-ray examinations require an appointment. Blood tests are walk-in only. A patient cannot make an appointment for a blood test. Some tests only require a sample. The patient drops off this sample. One example is a urine sample. Another example is a stool sample.

A patient makes an appointment for a requisition. The patient selects the desired lab. The lab has an address. The lab has business hours. The patient selects the lab by these. Some requisitions have repeated tests. For these requisitions, a patient may make only one appointment at a time. An appointment has a confirmation. The confirmation shows a confirmation number. The confirmation shows the date. The confirmation shows a start time. The confirmation shows an end time. The lab has a name. The confirmation shows this name. The lab has a registration number. The confirmation shows this number. A patient can change an appointment at any time. A patient can cancel an appointment at any time. A change within 24 hours incurs a fee. A cancellation within 24 hours incurs a fee. Each lab determines its own fee. Each lab determines its own business hours. All labs are open every day of the year. All labs offer all tests. The business hours do not change from one week to the next. Each day a lab opens at a start time. Each day a lab closes at an end time. There are no breaks.
