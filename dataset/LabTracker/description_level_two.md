The LabTracker software has two main purposes. First, the software helps doctors manage the requisition of tests and examinations for patients. Second, the software lets patients book appointments for these tests and examinations at a lab. In the rest of this description, the words "tests" and "examinations" mean the same thing.

For each requisition, a doctor must provide several details. These details are the doctor's numeric practitioner number and signature, which are both used for verification. The doctor must also give the doctor's full name, address, and phone number. The signature is a digital signature, which is an image of the doctor's actual signature. The doctor also indicates the date from which the requisition is valid. The requisition must show the patient's information too. This information includes the patient's alpha-numeric health number, first name, last name, date of birth, address, and phone number. A doctor cannot prescribe a test for that same doctor. However, a doctor can prescribe tests to someone else who is a doctor.

Several tests can be combined on one requisition, but only if the tests belong to the same group of tests. For example, only blood tests can be combined on one requisition. Alternatively, only ultrasound examinations can be combined. A blood test and an ultrasound examination cannot appear on the same requisition. The lab network defines the duration of each test, so that appointments can be scheduled accordingly. A test's duration is the same at every lab. For some kinds of tests, the number of tests performed does not matter. These tests take as long as a single test. For example, several blood tests can be done from one blood sample. Drawing the blood sample takes the same time for one blood test as for several blood tests.

A doctor may also indicate that the tests on a requisition should be repeated. When a doctor indicates repetition, the doctor gives a specified number of times and a certain interval. The interval is either weekly, monthly, every half year, or yearly. All tests on a requisition follow the same repetition pattern.

The doctor and the patient can view the result of each test, which is either negative or positive. The doctor and the patient can also view the accompanying report.

For some tests, a patient must make an appointment, while other tests are walk-in only. For example, x-ray examinations require an appointment. Blood tests are walk-in only, so no appointment can be made for a blood test. Some other tests only require a sample to be dropped off, such as a urine or stool sample.

To make an appointment for a requisition, a patient selects the desired lab. The patient bases this choice on the lab's address and business hours. For requisitions with repeated tests, a patient may only make one appointment at a time. The appointment confirmation shows a confirmation number, the date, and the start and end times. The appointment confirmation also shows the name of the lab and the lab's registration number. An appointment can be changed or cancelled at any time. However, if a patient changes or cancels within 24 hours of the appointment, the change or cancellation incurs a fee. Each lab sets the lab's own fee and business hours. All labs are open every day of the year. All labs offer all tests. A lab's business hours do not change from one week to the next. Each day, a lab is open from the day's start time to the day's end time, so there are no breaks.
