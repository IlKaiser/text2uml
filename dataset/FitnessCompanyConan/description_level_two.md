The fitness company "Conan" wants to build a database. The database is for its members and trainers. One goal is to record which members took part in which sessions. Another goal is to record which trainers supervised which sessions.

Conan runs several fitness centers. These centers are in various cities. Each center has a unique name, for example Fitplaza and my6pack. Each center has an address. Each center also has one or more rooms. You can treat the address as atomic. Each room has a maximum capacity. Within a center, each room has a unique number, such as 1, 2, 3, and so on.

People can register for individual sessions or group sessions. They register in different centers. Each group session requires exactly one trainer. Individual sessions have no trainer. For each person, the database stores the first name, family name, and birth date. You can assume this combination is unique. For each trainer, the database also records the diploma. A person can be a trainer in one session and a participant in another session. That other session can be an individual session or a group session. The model should also include people who have not yet taken part in any session, for example prospects. It should also include trainers who have not yet supervised any group session, for example interns.

For each session, the database records the date and starting hour. For group sessions, it also stores the type, for example aerobics or bodystyling. Sessions can start at the same time on the same day. But such sessions must be in different rooms of a center or in different centers. Take a given start hour on a given day. At that hour, at most one individual or group session can start in a given room of a given center.
