The fitness company "Conan" wants to build a database. The database is for members and trainers. One aim is to record which members took part in which sessions. Another aim is to record which trainers supervised which sessions.

Conan runs many fitness centers. The centers are in many cities. Each center has a unique name. Fitplaza is an example of a center name. My6pack is another example. Each center has an address. Treat the address as atomic. Each center has one or more rooms. Each room has a maximum capacity. Each room has a number. A room number can be 1. A room number can be 2. A room number can be 3. Each room number is unique within the center.

People can register for sessions in different centers. A session is individual or group. Each group session needs exactly one trainer. An individual session has no trainer. For each person, the database stores the first name. The database stores the family name. The database stores the birth date. Assume the combination of first name, family name, and birth date is unique. For each trainer, the database also records the diploma. A person can be a trainer in one session. The same person can be a participant in another session. The other session can be individual. The other session can also be group.

The model must also include people who have not yet taken part in any session. Prospects are an example. The model must also include trainers who have not yet supervised any group session. Interns are an example.

For each session, the database records the date. The database records the starting hour. For each group session, the database also stores the type. Aerobics is an example of a type. Bodystyling is another example. Sessions can start at the same time on the same day. Such sessions must be in different rooms of a center. Such sessions can also be in different centers. Take a given hour on a given day. Take a given room of a given center. At most one session can start there. That session is individual or group.
