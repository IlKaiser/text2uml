Boeing sells aircrafts to airline companies. Aircrafts are very expensive to build. Boeing builds them only "on demand". First Boeing makes a sales agreement with a customer. Then Boeing builds the airplane. Demo versions of airplanes are an exception. These demo versions are out of scope for this case.

Contracts regulate the sales. Boeing makes the contracts. Boeing makes them with the airline companies. A single contract may consist of several acquisitions. Each acquisition acquires airplanes. The global contract stipulates common elements. These elements apply across all acquisitions. These elements include delivery conditions. These elements include legal aspects.

Each acquisition acquires one airplane. Each acquisition has further specific details. These details include the chosen model. These details include the negotiated price. This price applies to that airplane. These details include chosen options. These details include chosen customizations. These details include the delivery date.

A Boeing salesperson manages each contract. An employee can act as salesperson. This employee can serve several contracts. Contracts have a long term. So the assigned salesperson may change over time. Boeing ensures a salesperson is always available. This salesperson serves the client.

Some airlines are related to each other. Main airlines often have a daughter airline company. This daughter is a low cost company. Boeing therefore keeps track of the mother-daughter relationships. These relationships hold between airline companies. Boeing tracks the movement of sold aircrafts. Sold aircrafts may shift to partner airlines. These partners belong to the original buyer.
