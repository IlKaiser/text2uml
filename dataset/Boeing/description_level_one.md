Boeing sells aircrafts to airline companies. Aircrafts cost a lot to build. So Boeing builds each aircraft only "on demand". First, Boeing makes a sales agreement with a customer. Then Boeing builds the airplane. Demo versions of airplanes are an exception. But demo versions are out of scope for this case.

Contracts with the airline companies control the sales. One contract can hold several acquisitions of airplanes. The global contract states common elements for all acquisitions. The common elements are delivery conditions, legal aspects, and more. Each acquisition of an airplane has more details. The details are the chosen model of airplane, the price for that airplane, chosen options, customizations, and the delivery date.

A Boeing salesperson manages each contract. One employee can be the salesperson for many contracts. Contracts run for a long time. So the salesperson for a contract can change over time. But Boeing always keeps a salesperson ready for the client.

Some airlines are linked to other airlines. For example, a main airline often has a low cost daughter airline company. So Boeing tracks the mother-daughter links between airline companies. Boeing tracks these links as much as Boeing can. These links help Boeing. Boeing checks if sold aircrafts move to partner airlines of the first buyer.
