The system stores the address of each house. The system stores the building material of each house. The building material is wood. The building material may be brick. The building material may be concrete.

A house may have a basement. A basement has a size. The system stores the size. A basement has a name. The system stores the name.

There are exactly two types of basements. One type is the earth basement. The other type is the concrete basement. An earth basement has a humidity level. The system also stores the humidity level.

A semi-detached house is a special type of house. A semi-detached house may have its own garden. The system stores this fact. A semi-detached house has some windows. The system stores the number of windows.

Each semi-detached house has two carports. It may instead have a garage. A carport may be a double carport. The system stores this fact. A carport may have a flat roof. The system stores this fact. A garage may have an automatic garage door. The system stores this fact.

Several companies service each house. A company has a name. The system stores the name. A company has an address. The system stores the address.

A company carries out a job. The job is in a house. A job has a number of hours. The system records the number of hours. The system uses a job log. A job has an agreed price. The system records the agreed price. The system uses the job log.
