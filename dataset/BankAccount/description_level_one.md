Here is a description of a bank. Use it to create a class diagram.

A bank manages any number of customers. Each customer has a first name and a last name. Both are of type String.

A bank has any number of branches.

A customer has at least one account. A customer has at most five accounts. Each account has an owner. The owner is a customer of the bank.

There are two basic types of accounts. These are current accounts and savings accounts.

Each account has an account number of type int. Each account also has a current account balance of type double.

A current account also has an overdraft limit of type double.
