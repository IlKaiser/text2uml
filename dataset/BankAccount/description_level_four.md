A description of a bank is given. Create a suitable class diagram from this description.

A bank manages any number of customers. Each customer has a first name. The first name has type String. Each customer has a last name. The last name has type String.

A bank consists of any number of branches.

A customer has at least one account. A customer has at most five accounts. Each account has an owner. The owner is a customer of the bank.

Accounts have two basic types. The first type is a current account. The second type is a savings account.

Each account has an account number. The account number has type int. Each account has a current account balance. The balance has type double.

A current account also has an overdraft limit. The overdraft limit has type double.
