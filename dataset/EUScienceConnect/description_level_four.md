The European Union recently made funds available. These funds set up a research database. The database is cross-national. The database stores information. This information concerns scientific articles. Researchers write these articles. These researchers work at institutions. These institutions are in the EU. Science Connect is a company. Science Connect will set up this database.

The system stores information. This information concerns scientific staff. Scientific staff are persons. The system also stores information. This information concerns research institutions. A person ID identifies each person. This identification is unique. An institution code identifies each institution. This identification is unique. The system records a phone number. It records this number for each person. The system records keywords. It records these keywords for each person. The keywords identify the research topics. These topics are the key topics. These topics belong to the person. The system records the institution. It records this institution for each person. The person works for that institution. A person can be an author. This author writes one article. That same person can be a reviewer. This reviewer reviews another peer-reviewed article. This happens at the same time.

The database stores information. This information concerns scientific articles. A DOI identifies each scientific article. This identification is unique. A DOI is a document object identifier. The system stores the title. This title belongs to the article. The system stores the authors. These authors belong to the article. An article can have multiple authors. The system stores the position. This position belongs to each author. Science Connect distinguishes between two types. These types are scientific articles. A scientific article is a peer-reviewed paper. A scientific article is a technical report. The system stores the citation count. This count belongs to peer-reviewed papers. The system stores the reviewer. This reviewer reviewed the paper. A single research institution publishes a technical report. This is always the case. A research institution can publish multiple technical reports.

The system keeps track of the publishers. These publishers are scientific. These publishers are different. Examples are IEE and Elsevier. A name identifies a publisher. A publisher can publish multiple journals. Research institutions can subscribe to these journals. The publisher gives each journal a name. An example is Decision Support Systems. A publisher can have a journal. Another publisher can have a journal. Both journals can have the same name. For example, IEE can have a journal. This journal is titled Management Science. Elsevier can also have a journal. This journal is titled Management Science. The system also stores the impact factor. The impact factor measures the impact. This impact is scientific. This impact belongs to a journal.

Journals publish only peer-reviewed papers. Journals do not publish technical reports.
