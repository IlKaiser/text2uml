The European Union recently gave money to set up a research database. This database spans many nations. The database stores facts about scientific articles. The articles come from researchers. The researchers work at institutions in the EU. A company called Science Connect will set up this database.

The system will store facts about scientific staff. The scientific staff are persons. The system will also store facts about research institutions. Each person has one person ID. The person ID is unique. Each institution has one institution code. The institution code is unique. The system records more facts for each person. The system records a phone number. The system records keywords. The keywords name the key research topics of the person. The system records the institution where the person works. A person can be an author of one article. At the same time, the same person can be a reviewer of another peer-reviewed article.

The database will store facts about scientific articles. Each scientific article has one DOI. The DOI is unique. DOI means document object identifier. The system stores the title of the article. The system stores the authors of the article. Sometimes an article has many authors. Then the system stores the position of each author. Science Connect uses two types of scientific articles. An article is a peer-reviewed paper or a technical report. For each peer-reviewed paper, the system stores the citation count. For each peer-reviewed paper, the system stores who reviewed the paper. One research institution always publishes a technical report. A research institution can publish many technical reports.

The system keeps track of the scientific publishers. IEE and Elsevier are two examples. Each publisher has a name. The name identifies the publisher. A publisher can publish many journals. Research institutions can subscribe to these journals. The publisher gives each journal a name. Decision Support Systems is one example. Two publishers can have journals with the same name. For example, IEE and Elsevier can both have a journal named Management Science. The system also stores the impact factor. The impact factor measures the scientific impact of a journal.

Finally, only peer-reviewed papers are published in journals. Technical reports are not published in journals.
