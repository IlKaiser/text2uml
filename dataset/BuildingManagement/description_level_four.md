Project description:

Each web portal has a version number. Each web portal has a URL address. One example URL address is "http://www.ebuntu-nrw.org". Each web portal provides a catalog. The catalog lists buildings. Each building has energy information. The catalog shows this information.

A building has a unique ID. A building has a name. A building has an energy class. The energy class is A, B, C, or D. A building has an address. A building has a year of construction. A building is assigned to a user. This user is the owner. The owner can add additional entries. The owner adds these entries to the building.

Each additional entry has a name. An entry can be textual information. An entry can be a floating point number. This number has an additional unit. The unit is freely definable text.

The owner can release each additional entry publicly. This release is optional. A released entry is visible to all non-registered visitors. These visitors belong to the web portal.

Each building has a number of images. One image serves as a profile photo. Each image has a file name.

Visitors can register with a web portal. A visitor registers as a user. A user has a unique user name. A user has an email address. A user has a password. The system checks the user name during registration. The system checks the user name for uniqueness. The system checks the email address for correctness. The system sends a confirmation link. Meanwhile an administrator sets up the user. This setup is for the web portal.

These processes are then completed. The system then informs users automatically. The system uses email. The email states one fact. The users have been activated. The users can then log in.

Users log in. Users can then create buildings. Users can manage entries for their buildings. Users can comment on other users' buildings. All site visitors can search for buildings. They search in the system. This search uses a full-text search.

Administrators are special users. An administrator has an ID card number. The system stores this number in addition to the user information. Administrators set up user accounts. Administrators delete comments.
