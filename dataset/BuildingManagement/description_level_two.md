Project description:

Each web portal has a version number and a URL address, such as "http://www.ebuntu-nrw.org". Each web portal provides a catalog of buildings with their energy information. A building has a unique ID, a name, an energy class (A, B, C, D), an address, and a year of construction. A building is assigned to a user as its owner. The owner can add extra entries to the buildings. Each extra entry has a name. An entry can be textual information. An entry can also be a floating point number with an extra unit. The unit is freely definable text. The owner can choose to make each extra entry public. This means the entry is also visible to all non-registered visitors of that web portal. Each building also has a number of images. One image is used as the profile photo. Each image is saved with a file name.

Visitors can register with a web portal as a user. To register, they give a unique user name, their email address, and a password. During registration, the system checks that the user name is unique. It also checks the email address by sending a confirmation link. Meanwhile, an administrator sets up the user for the web portal. When both steps are done, the system tells the user by email that the account is active. The user can then log in. After logging in, users can create buildings. They can manage entries for their own buildings. They can also comment on other users' buildings. All visitors to the site can search for buildings in the system with a full-text search. Administrators are special users. Their ID card number is stored in addition to their user information. Administrative functions include setting up user accounts and deleting comments.
