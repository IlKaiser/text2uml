Facepage is a new social network site. Facepage was founded recently. Facepage has managers. The managers consider current trends. The managers are convinced. Facepage will be the new hype in the near future.

A new user wants to join Facepage. The user first fills in a form. The form holds personal information. This information is the ID. This information is the name. This information is the email. This information is the date of birth. A user has an ID. The ID is unique. The system then creates an account. An account has an account number. The account number is unique. The database system generates the account number automatically. The user specifies a preferred account type. This type is a business account. This type can also be a personal account.

A business account supports companies. Companies run marketing campaigns. A user decides to open a business account. The user then specifies the company name. A user has a business account. This user pays a monthly fee. A user opts for a personal account. This user keeps in touch with other Facepage users. Only personal accounts send friend requests. Only personal accounts receive friend requests.

A user must not maintain multiple accounts. This rule ignores the purpose. Multiple accounts violate Facepage's Terms of Use. A user already has a personal account. A user already has a business account. Facepage forbids an additional personal account. Facepage forbids an additional business account. This holds for any reason.

Each account creates several pages. Exactly one account administrates each page. A personal account can be granted privileges. These privileges apply to pages. These pages belong to other personal accounts. One privilege writes something on the wall of friends. Another privilege adjusts some information. The system logs the page name. The system logs the number of visits. This logging happens for each page. One account cannot own two pages with the same name.

A user has a business profile. This user creates a special page type. This type is an advertisement page. An advertisement page records several features. One feature is the bounce rate. One feature is the click-through rate. One feature is the conversion rate. The bounce rate counts certain visitors. These visitors are on the page. These visitors leave immediately. The bounce rate is a percentage. The click-through rate counts certain visitors. These visitors click a certain banner. The banner is on the page. The click-through rate is a percentage. The conversion rate counts certain visitors. These visitors accomplish the intended goal. The conversion rate is a percentage. The goal is a purchase. The goal can also be a transaction.
