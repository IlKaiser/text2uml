Locations consist of drivers. Locations consist of vehicles. A driver has a first name. A driver has a last name. Each location has its own address.

There are three types of vehicles. The first type is truck. The second type is car. The third type is van. Each vehicle has a vehicle number. A truck has a certain weight. A car has a certain number of seats.

The system also manages orders. A driver carries out orders. A driver carries out one order at a time at most. The system assigns that order to the driver.

An order has an origin location. An order has a destination location. An order has one assigned driver at least. An order has a date of execution.

The system also records driver assignments. A driver drives vehicles. The system assigns up to one driver to a vehicle. That driver drives that vehicle.
