Each location has drivers and vehicles. Each driver has a first name and a last name. Each location has its own address.

There are three types of vehicles. These are trucks, cars, and vans. Each vehicle has a vehicle number. A truck also has a weight. A passenger car also has a number of seats.

The system also manages orders. It manages vehicles, drivers, and orders. Drivers carry out orders. At any one time, a driver carries out at most one order assigned to them.

Each order has an origin location and a destination location. Each order has at least one assigned driver. Each order has a date of execution.

The system also records which vehicles are driven by which driver. For this, each vehicle is assigned up to one driver. That driver drives the vehicle.
