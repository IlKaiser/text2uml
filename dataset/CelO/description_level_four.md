# Celebrations Organization System

The CelO application helps families organize events. It helps groups of friends organize events. The events include birthday celebrations. The events include other events. Organizers track completed tasks. Organizers track attendees. Attendees indicate what they bring to the event.

A small event typically has one organizer. A larger event requires several organizers. An organizer provides a first name. An organizer provides a last name. An organizer provides an email address. The email address is also the username. An organizer provides a postal address. An organizer provides a phone number. An organizer provides a password.

An organizer indicates the kind of event. The organizer selects the kind from a list. The list includes birthday party. The list includes graduation party. The organizer can instead create a new kind of event.

The organizer must specify a start date/time. The organizer must specify an end date/time. The organizer must specify an occasion. The organizer must specify a location. The organizer can select the location from a list. The organizer can instead create a new location. The organizer specifies a name for the new location. The organizer specifies an address for the new location.

The organizer then invites the attendees. The organizer enters each attendee first name. The organizer enters each attendee last name. The organizer enters each attendee email address. Sometimes an organizer only manages the event. This organizer does not attend the event. Sometimes an organizer also attends the event.

An attendee receives the email invitation. The attendee can create an account. This applies without an existing account. The attendee sets a new password. The attendee uses the invitation email address. This email address is the username. Afterwards the attendee indicates a response. The attendee can indicate they will attend. The attendee can indicate they maybe will attend. The attendee can indicate they cannot attend.

An organizer can view the invitation status. The status shows how many attendees replied. The status shows how many attendees did not yet reply. The status shows who is coming for sure. The status shows who maybe is coming.

An organizer selects an event. The system presents an event-specific checklist. The system presents it to the organizer. For example, a birthday party may have a task. This task is to bring a birthday cake. An organizer sets a state for each task. The organizer can indicate the task needs to be done. The organizer can indicate the task is done. The organizer can indicate the task is not applicable.

An organizer can add new tasks. A new task is also available for the next event. For example, an organizer can add a task. This task is to bring birthday candles. The organizer adds it to a birthday party list. This task is then available for the next birthday party.

An organizer can designate a task for attendees. Attendees accomplish this task. For example, an organizer can indicate an attendee brings the birthday cake. The system then shows a list of attendee tasks. The system shows this list to attendees. These attendees confirmed their attendance. An attendee can then select their tasks. The organizer can then see who brings what.
