Your company has a job. You must build an application for a company that sells clothing. The application manages customers, products, orders, and similar items. You will design this application. The customer gives you the following information:

"We sell all kinds of clothing. We have everything from shoes to headwear. Each product has a unique name, a description, and a net price. We also know which company made each product. We know the country where it was made.

We want to calculate the gross price of an item. The gross price depends on the local VAT rate in each country. So we need some facts for each country. We need the VAT rate. We need the currency used. We need a conversion rate to the euro.

We do not sell every product in every country. We want to be able to query this too.

Representatives distribute our products. For each representative, we must store the first name and last name. We must also store the social security number, the telephone number, and the email address. Each representative is responsible for exactly one country.

For each customer, we store the name, the address, the telephone number, and the email address. We also store the countries where the customer resells our goods.

The representatives place the orders from customers. Each order has a unique identifier. Each order refers to exactly one product. Each order must include the order quantity, the order date, and the desired delivery date."
