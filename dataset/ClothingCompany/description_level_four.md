Your company develops an application. The application manages customers. It manages products. It manages orders. It manages similar items. The application serves a company. The company sells clothing. You design the application. The customer gives you this information:

"We offer all kinds of clothing. We offer shoes. We offer headwear. We have everything in our range. Each product has a unique name. Each product has a description. Each product has a net price. A company manufactures each product. We know that company. A country produces each product. We know that country. We calculate the gross price. The gross price depends on the local VAT rate. Each country has a local VAT rate. We need the VAT rate. We need the currency. We need a conversion rate to the euro. We need this for each country. We do not sell every product in every country. This must be queryable in some way.

Representatives distribute our products. We store each representative's first name. We store each representative's last name. We store each representative's social security number. We store each representative's telephone number. We store each representative's email address. Each representative is responsible for exactly one country.

The customer data includes a name. The customer data includes an address. The customer data includes a telephone number. The customer data includes an email address. The customer data includes the countries. The customer resells our goods in those countries.

The representatives place orders from customers. Each order is uniquely identifiable. Each order refers to exactly one product. Each order includes the order quantity. Each order includes the order date. Each order includes the desired delivery date.
