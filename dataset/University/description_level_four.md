A university consists of several faculties. A faculty contains various institutes. Each faculty has a name. Each institute has a name. Each institute has an address.

A dean heads each faculty. A dean is a university employee.

The university knows the total number of employees. An employee has a social security number. An employee has a name. An employee has an email address. Employees include research staff. Employees include administrative staff.

A research assistant (RA) belongs to at least one institute. Each RA has a field of research. An RA can join projects. This work lasts a certain number of hours. A project has a name. A project has a start date. A project has an end date. Some RAs teach courses. The university calls such an RA a lecturer.

A course has a unique number (ID). A course has a name. A course has a weekly duration in hours.
