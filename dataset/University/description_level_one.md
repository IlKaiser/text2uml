A university has several faculties. Each faculty is made up of various institutes. Each faculty has a name. Each institute has a name. Each institute has an address.

Each faculty is headed by a dean. The dean is an employee of the university.

The total number of employees is known. Each employee has a social security number. Each employee has a name. Each employee has an email address. Employees are split into research staff and administrative staff.

Each research assistant (RA) is assigned to at least one institute. The field of research of each RA is known. An RA can also work on projects for a certain number of hours. Each project has a name. Each project has a start date. Each project has an end date. Some RAs teach courses. Then they are called lecturers.

Each course has a unique number (ID). Each course has a name. Each course has a weekly duration in hours.
