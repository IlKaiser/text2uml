100% Driven by technology

Sober is a new taxi company. Sober deploys self-driving cars. These cars provide cab services. Sober operates its own fleet. This fleet has self-driving cabs. People can also register their cars. These cars become Sober cabs. These cars provide taxi services. The owners are not using their cars then. Sober also tracks the car owners.

Sober offers two types of taxi services. The first type is ride-hailing. The second type is ride-sharing.

Ride-hailing is a service. Customers can hail a taxi. Sober picks up the customers. Sober drives the customers to their destination. Sober charges a fee. The fee is based on time. The fee is also based on distance.

The hailing is immediate. The hailing is on-demand. Customers can make requests. Customers use the Sober App. A customer taps the screen once. The customer can request a cab from anywhere. The customer receives an estimated wait time. The car arrives. Then the customer receives a notification.

Users can also hail Sober cabs. Users wave their hands. The users see the cabs pass. Sober uses an image recognition system. This system uses deep learning. This system identifies the wave gesture. The system treats the gesture as a cab request.

Sober wants to store data. Sober stores this data for each ride-hail use. Sober stores the pick-up time. Sober stores the drop-off time. Sober stores the pick-up location. Sober stores the drop-off location. Sober stores the ride duration. Sober stores the distance. Sober stores the passenger count. Sober stores the fee. Sober stores the request type. The request type is via Sober App. The request type is also via hand-waving. Sober stores the lead customer number. Sober stores the lead customer name. The lead customer pays.

The maximum passenger number is six. This limit applies to a ride-hail service.

Ride-sharing is another service. Sober offers this service. This service requires more careful planning. People can also call ride-sharing carpooling. Ride-sharing aims to reduce costs. Ride-sharing aims to reduce traffic congestion. Ride-sharing aims to reduce the carbon footprint.

Sober can negotiate the fee. Its customers can negotiate the fee. More customers per cab means a lower fee per customer. This is flexible pricing.

Sober provides an eco-friendly incentive. Sober pledges to plant a tree. Sober plants one tree per customer. The customer books 20 uses. These uses are of the Sober ride-sharing service.

Sober wants to store data. Sober stores this data for each ride-share service. Sober stores the pick-up time. Sober stores the drop-off time. Sober stores the pick-up location. Sober stores the drop-off location. Sober stores the ride duration. Sober stores the distance. Sober stores the customer count. Sober stores all customer names. Sober stores the upfront negotiated fee.

The maximum passenger number is ten. This limit applies to a ride-share service.

The self-driving car technology is novel. Accidents cannot be fully ruled out. Sober also stores information per car. Sober stores accident dates. Sober stores accident locations. Sober stores damage amounts.
