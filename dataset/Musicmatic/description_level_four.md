Spotify is successful. This success attracts a group of students. The students want their own music streaming website. This website is called Musicmatic. The students are economists. They are unaware of the specificities of databases. They have therefore asked you. You must create a UML class diagram.

The website makes many songs available. The system stores information on each song. A song has a title. A song has a year. A song has a length. A song has a genre. The system also stores artist information. An artist has a date of birth. An artist has a name. An artist has a URL. The URL points to a website. This website holds additional information. This information is about the artist. The Wikipedia page is an example. A name identifies each artist uniquely. A song always belongs to exactly one artist. Songs can have the same title. Only the combination of song and artist is unique.

The database also stores information. This information is about people. These people use Musicmatic. These people are the users. There are two types of users. The first type is the regular user. The second type is the business user. A regular user can buy music. A business user delivers the content. A business user uploads the music. The system records information on each user. A user has a unique ID. A user has a name. A user has an address. A business user also has a VAT number.

The students want a flexible service. A business user can only upload individual songs. Each song is a single or a hit. A regular user can directly buy a single. A regular user can compose an album. An album consists of multiple hits. An album contains no singles. The database stores the position of each hit. This position is within the album. This position is a track number.

A regular user has an album. This album can become a suggestion. This suggestion goes to other regular users. These other regular users have similar purchasing behavior.

A user can be a regular user on some occasions. For example, the user downloads a single. The user also downloads an album. A user can be a business user at other times. For example, the user uploads self-made songs to Musicmatic.
