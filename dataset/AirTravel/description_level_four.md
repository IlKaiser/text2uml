An aircraft has a name. An aircraft has a type. An aircraft has a manufacture year. An aircraft has a next-inspection date. The system stores these facts. It stores them per aircraft.

An aircraft performs several flights. A flight has a flight number. A flight has a date. The system stores these facts. It stores them per flight.

Several passengers take part in a flight. A passenger has a name. A passenger has a passport number. The system stores these facts. It stores them per passenger. A passenger can take part in several flights.

Each flight has a personalized ticket. A ticket has a ticket number. A ticket has a price. The system stores these facts. It stores them per ticket. The system also stores an upgrade wish.

Passenger aircraft are special aircraft. Passenger aircraft transport only passengers. The system stores a seat count. It stores this count per passenger aircraft.

A passenger aircraft can have several seat categories. A seat category has a designation. A seat category may offer an entertainment program. A seat category has a seat count. The system stores these facts. It stores them per category. Each ticket names one seat category.

Each aircraft can belong to an airline. An airline has a name. The system stores this name.

An airline employs several flight attendants. An airline employs several pilots. A flight attendant has a name. A flight attendant has an employment date. A flight attendant may be a chief steward or stewardess. The system stores these facts. It stores them per flight attendant. A pilot has a name. A pilot has an employment date. A pilot has a license. The system stores these facts. It stores them per pilot.

Several flight attendants work on a flight. One pilot flies the aircraft. This pilot is the captain. One or two other pilots act as co-pilots.

An airport has a name. An airport has an address. An airport has a runway count. The system stores these facts. It stores them per airport. Each aircraft can have a home airport. Each flight has a departure airport. Each flight has a destination airport.
