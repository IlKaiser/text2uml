Each aircraft has a name. It has a type. It has a year of manufacture. It has a date when its next inspection is due.

An aircraft performs several flights. Each flight has a flight number. Each flight has a date.

Several passengers take part in a flight. Each passenger has a name. Each passenger has a passport number. One passenger can take part in several flights.

Each flight has a personalized ticket. The ticket has a ticket number. The ticket has a price. The ticket also stores whether an upgrade is wished.

A passenger aircraft is a special aircraft that carries only passengers. It also stores the number of seats.

A passenger aircraft can have several seat categories. Each category has a name. Each category stores whether it offers an entertainment program. Each category stores how many seats it has. Each ticket is for one specific seat category.

Each aircraft can belong to an airline. The airline has a name.

An airline employs several flight attendants. An airline also employs several pilots. Each flight attendant has a name. Each flight attendant has a date of employment. The system also stores whether the attendant is a chief steward or stewardess. Each pilot has a name. Each pilot has a date of employment. Each pilot has a license.

Several flight attendants work on a flight. One pilot flies the aircraft as the captain. One or two other pilots act as co-pilots.

Each airport has a name. Each airport has an address. Each airport has a number of runways. Each aircraft can have a home airport. Each flight has a departure airport. Each flight has a destination airport.
