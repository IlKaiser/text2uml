For each aircraft, the system stores the name, type, year of manufacture, and the date of the next inspection. An aircraft performs several flights. Each flight has a flight number and a date.

Several passengers take part in a flight. Each passenger has a name and a passport number. A passenger can take part in several flights. For each flight, a personalized ticket is stored. The ticket has a ticket number and a price. It is also recorded whether an upgrade is desired.

Passenger aircraft are a special kind of aircraft. They are used only to transport passengers. For these aircraft, the number of seats is also stored.

A passenger aircraft can have several seat categories. Each category stores its designation. It also stores whether it offers an entertainment program. It stores how many seats it contains. Each ticket applies to a specific seat category.

Each aircraft can belong to an airline. The name of the airline is stored. An airline employs several flight attendants and pilots. For each flight attendant, the name and date of employment are stored. The system also stores whether the attendant is a chief steward or stewardess. For each pilot, the name, date of employment, and license are stored.

Several flight attendants work on a flight. One pilot flies the aircraft as the captain. One or two other pilots act as co-pilots.

For each airport, the name, address, and number of runways are stored. Each aircraft can have a home airport. Each flight has a departure airport and a destination airport.
