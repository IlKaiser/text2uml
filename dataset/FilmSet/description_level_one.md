Many employees work on a film set. Each employee has a name. Each employee has a social security number.

Some employees are creative. Creative employees include directors and actors. Each actor has a completed education. This completed education is known. Each director has an assistant. The assistant's name is stored.

Directors and actors can win an Oscar. For each director and each actor, the system stores whether the person has an Oscar.

There are also technicians. Each technician has a field of activity. The field of activity is known.

A film set is at a specific location. One film set can be used for several films. One film can be shot at several film sets. Each film has a title. Each film has a year of release. Each film has one genre. The genre is a thriller, an action film, a horror film, or a comedy.

A screenwriter has a name. A screenwriter has a most successful film. The name and the most successful film are stored. One screenwriter creates several screenplays. Each screenplay comes from exactly one screenwriter.

Each screenplay has a title. Each screenplay has a version. Each screenplay has a date. Each screenplay has a number of scenes. Each screenplay has a plot. The title, version, date, number of scenes, and plot are known.

A screenplay is based on a novel or on a concept. Each novel has a title. Each novel has an author.

A film shot on a film set is based on one specific screenplay. Each screenplay is written for exactly one film. The actors in the film must prepare for their roles. The actors prepare by reading the screenplay. The director of the film then puts the screenplay into practice. The director follows the specifications.
