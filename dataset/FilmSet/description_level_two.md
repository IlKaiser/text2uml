Several employees work on a film set. Each employee has a name and a social security number. Some employees are creative, such as directors and actors. Each actor has a completed education. Each director has an assistant, whose name is stored. Directors and actors can be Oscar winners. So it is stored whether the person has an Oscar. There are also technicians. Each technician has a field of activity.

The film set is at a specific location. One film set can be used for several films. One film can be shot at several film sets. Each film has a title and a year of release. Each film belongs to one genre. The genre is thriller, action, horror, or comedy.

Each screenwriter has a name and a most successful film. A screenwriter creates several screenplays. Each screenplay comes from exactly one screenwriter. Each screenplay has a title, version, date, number of scenes, and plot. A screenplay is based on a novel or on a concept. Each novel has a title and an author. A film shot on a film set is based on one screenplay. Each screenplay is written for exactly one film. The actors in the film must prepare for their roles by reading the screenplay. The director then implements the screenplay according to the specifications.
