Students can ask questions about the courses that the students follow. To ask these questions, students make an appointment with the teaching assistants of those courses. The demand for appointments is high. So a system is built to keep track of every appointment between a teaching assistant and a student (or students).

A student can only request an appointment for a course if the student is registered for that course. A teaching assistant can only give help for the courses that the teaching assistant teaches.

An appointment is always for one specific course. An appointment is always with one particular assistant. That assistant must be a teaching assistant (TA) for that course.
