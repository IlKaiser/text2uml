Students follow courses. A student can ask questions about a course. To ask questions, a student makes an appointment. The appointment is with a teaching assistant of that course.

Many students want appointments with teaching assistants. So a system is made to handle the high demand. The system keeps track of every appointment. Each appointment is between one teaching assistant and one or more students.

A student can request an appointment for a course only if the student is registered for that course. A teaching assistant can help only with the courses that the teaching assistant teaches.

An appointment is always for one course. An appointment is always with one teaching assistant. That teaching assistant must be a TA for that course.
