A school has a name. Teachers work at the school, and students attend classes there. Both students and teachers have a recorded first name and last name. In addition, each teacher has a known email address.

A student attends exactly one school. A teacher can teach at up to three schools. For each teaching relationship, the number of hours is known. Each school has exactly one principal, chosen from among the teachers. A teacher may teach at several schools, but can be the principal of only one school.

Besides the people who work there, a school also has many rooms. Some rooms are classrooms, which have a name and a capacity. Other rooms, such as a gym, have a name and a size in square meters.

Between 10 and 31 students form a class group. Each class group has a name, for example "5a". A student always belongs to exactly one class group. Each class group is assigned to exactly one classroom, and each classroom is assigned to exactly one class group.
