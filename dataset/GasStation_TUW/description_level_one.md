A gas station chain wants to manage its gas stations electronically. Model this with a UML class diagram. Use the information below.

Each gas station has a unique ID. Each gas station has an address. Each gas station has fuel pumps. A gas station can have at most 12 fuel pumps. Each fuel pump has a number to identify it. For each fuel pump, note if it is a self-service pump or not. For each fuel pump, note which fuels it offers.

Each fuel has a name. The name identifies the fuel uniquely. Each fuel also has an octane rating.

Each gas station archives all daily fuel prices. A daily price is identified by three things. These are a date, the fuel it applies to, and the gas station. A daily price also has a price per liter.

A fuel purchase has a unique ID. For each purchase, note at which fuel pump the fuel was bought. Also note which fuel was bought. Also note at which daily price it was bought. Also note the number of liters of fuel dispensed.
