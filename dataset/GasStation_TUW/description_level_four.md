A gas station chain owns gas stations. The chain wants to manage them electronically. This will happen in the future. Model this situation. Use a UML class diagram. Base it on the following information.

Each gas station has a unique ID. Each gas station has an address. Each gas station has fuel pumps. A gas station has at most 12 fuel pumps. Each fuel pump has a number. The number identifies the fuel pump. A fuel pump may be a self-service fuel pump. The system notes this fact. Each fuel pump offers fuels. The system knows these fuels for each fuel pump.

A fuel has a name. The name uniquely identifies the fuel. A fuel has an octane rating. The system notes this rating.

Each gas station archives all daily fuel prices. A daily price has a date. A daily price applies to one fuel. A daily price belongs to one gas station. The date identifies the daily price. The fuel identifies the daily price. The gas station identifies the daily price. A daily price has a price per liter. The system notes this price.

A fuel purchase has an ID. The ID uniquely identifies the fuel purchase. A fuel purchase occurs at one fuel pump. The system notes this fuel pump. A fuel purchase buys one fuel. The system notes this fuel. The purchase uses one daily price. The system notes this daily price. A fuel purchase dispenses a number of liters. The system stores this number.
