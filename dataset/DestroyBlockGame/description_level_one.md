The DestroyBlock application works in two parts. First, a game admin designs a DestroyBlock game. Then players play the game. Players compete for an entry in the game's hall of fame.

DESIGN GAME: A user has a unique username. A user is always a player. A user can also be an admin. A user has the same password as a player and as an admin. The user chooses the admin mode or the play mode when logging into the application. Only an admin may create a game.

Each game has a unique name. Each game has its own hall of fame. The admin designs a game by defining a set of blocks. Each block has a color. Each block is worth a certain number of points. The admin sets these points between 1 and 1000.

A game has several levels. The admin defines the levels. Levels are numbered starting with Level 1. The maximum number of levels is 99. For each level, the admin specifies the starting arrangement of blocks. Each block is placed in one cell of a grid system. The block at the top left corner is in grid position 1/1. The block to the right of it is in grid position 2/1. The block below it is in grid position 1/2. The rest follow the same pattern. The admin may also define a level as random. This means the blocks at the top are chosen at random for the level. They are chosen from the set of blocks defined by the admin.

The number of blocks shown at the beginning of each level is the same. The admin also defines this number. With each level, the speed of the ball increases. The ball starts at its minimum speed. With each level, the length of the paddle is reduced gradually. The paddle goes from its maximum length to its minimum length. The admin specifies the minimum speed, the speed increase factor, the maximum length, and the minimum length for the game.

PLAY GAME: A player can play a game when the game admin publishes it. At the beginning of a game or level, the DestroyBlock application places the blocks at the top of the play area. It places them as the admin specified in the design phase. The ball is placed in the center of the play area. The ball drops in a straight line towards the bottom. The player's paddle is placed in the middle at the bottom of the play area. The player moves the paddle to the right or left at the bottom of the play area. The player tries to bounce the ball towards the blocks. The ball moves at a certain speed in a certain direction. The ball bounces back from the top wall. The ball also bounces back from the two side walls on the right and left. The ball may hit a block. Then the ball bounces back. Then the block disappears. Then the player scores the points of the hit block.

When the ball hits the last block, the player advances to the next level. The ball may reach the bottom wall. Then the ball is out-of-bounds. Then the player loses one life. The player starts a game with three lives. The player may lose all three lives. The player may also finish the last level. In either case, the game ends. The total score is shown in the game's hall of fame.

The game is saved at the end of a level. The game is also saved when the player pauses the game. The player can resume a paused game. The next level of a game does not start automatically. It starts only when the player confirms it.

A user may be a player for one game and an admin for another game. A user cannot be both for the same game. There is only one admin per game. Players compete against each other for the high score in the game's hall of fame. A player may play different games. A player may play the same game multiple times. But only one game may be played at any point in time. This means games are not played in parallel.
